Avant de commencer

Ces informations personnalisent votre profil — elles restent sur cet appareil.

Ce carnet explore 6 dimensions de votre personnalité professionnelle selon le modèle RIASEC de John Holland : Réaliste, Investigateur, Artistique, Social, Entreprenant et Conventionnel. Pour chaque dimension, cochez toutes les activités qui vous attirent — il n'y a pas de bonne ou de mauvaise réponse. Vos trois dimensions les plus fortes formeront votre code d'orientation personnel.
